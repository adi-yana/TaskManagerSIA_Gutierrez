How to Use Task Manager

Welcome to your Task Manager! Manage your tasks, set due dates, and mark them as done.

  • Add Tasks: Use the form to add a new task with a due date, priority, and category.
  • Mark as Completed: Click the checkmark button to mark a task as done.
  • Edit Tasks: Click the pencil icon to edit a task's details.
  • Delete Tasks: Click the trash icon to remove a task.
  • Filter: View all, completed, or pending tasks using the filter buttons.
  • Search: Use the search bar to find tasks quickly.
